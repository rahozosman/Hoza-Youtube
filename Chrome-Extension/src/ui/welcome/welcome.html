Install the Hoza YT app

The extension finds the media and manages the queue. The downloading itself — and everything YouTube needs — happens in the Hoza YT app on your computer. Install it once and it takes care of itself from then on.

  1. Run HozaYT-Setup.exe

    It is in the folder named 1 - Install the app, next to the one you just loaded into Chrome. Double-click it and follow the installer.

  2. That is the whole step

    The installer connects Hoza YT to your browser and starts the engine. Nothing needs to be launched, configured or left open — the app starts by itself whenever this extension needs it.

  3. Come back here

    The banner above turns green the moment the app answers. Then open a video page and click the Hoza YT icon in the toolbar.

Already installed it?

Open Hoza YT from the Start menu once, then press Check again. If it still does not answer, run HozaYT.exe --verify from the install folder — it checks the browser connection and reports what is wrong.

Running from source instead?

Start the development server with python server/server.py from the project folder. It listens on 127.0.0.1:8765, which is where the extension looks when no installed app answers.

You can reopen this page from the panel at any time.
