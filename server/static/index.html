What this application will not do

  • It does not bypass DRM, sign-in walls, or any other access control.
  • It does not invent formats. Every quality listed comes from the source.
  • It does not claim an output format the installed ffmpeg cannot produce.
  • It does not download live streams, which have no fixed end.
  • It does not delete your downloaded files when you remove a record.
