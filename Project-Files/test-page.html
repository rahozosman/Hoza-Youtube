Hoza YT test page

Every item below is content that is genuinely free to download — public test streams and Creative-Commons video. Open the Hoza YT panel on this page and each of the three should be detected.

How to run this test
  1. Open the Hoza YT panel while on this page.
  2. The MP4 below is in a real <video> tag and a direct link, so it is detected with no extra permission.
  3. For the HLS and DASH items, click Grant access to this site in the panel — that is when Hoza YT requests the optional webRequest permission — then Scan again.

1. Progressive MP4 — Big Buck Bunny (CC-BY)

Delivered as one file, so it downloads through the browser's own engine with real pause and resume.

Direct link: BigBuckBunny.mp4

2. HLS — unencrypted multi-quality stream (Mux public test)

A master playlist with several resolutions. Hoza YT reads the variants, lets you pick one, then fetches and joins the segments.

x36xhzz.m3u8 (HLS master)

3. DASH — unencrypted stream (Akamai public test)

A DASH manifest that separates video and audio tracks — which is exactly where Hoza YT shows Video only and Audio only, because it saves tracks as delivered rather than muxing them.

bbb_30fps.mpd (DASH manifest)
What this proves

If all three are detected and download, Hoza YT is working end to end: DOM detection, network observation, HLS parsing, DASH parsing, progressive download and segment assembly. Sites that expose media openly — like these — are what it is built for. Sites that lock their streams behind signatures and throttling, like YouTube, are the ones it deliberately leaves alone.
